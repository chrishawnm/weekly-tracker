Rules & settings

Add, remove, or change anything.

Rule types: “At most” charges for each checked day above the limit. “At least” charges for each day below the target. “Every day” charges for each missed day. Future days in the current week do not count as missed yet.

Data stays in your browser using local storage. No account or server required.
